# Bugti Editz — APK Download

This folder is prepared in the repository root for hosting the **Bugti Editz** Android APK.

## How to Add Your Working APK Download Link
1. In **Google AI Studio**, open the settings/export menu and generate/download the Android APK (`app-debug.apk` or release `.apk`).
2. In your GitHub repository:
   - **Option A (Direct folder upload):** Open this `Download/` folder on GitHub, click **Add file → Upload files**, upload your `.apk` file, and commit to `main`. Your direct download URL will be:
     `https://github.com/<your-username>/<your-repo>/raw/main/Download/<your-apk-filename>.apk`
   - **Option B (GitHub Releases — recommended for larger APKs):** Go to **Releases → Create a new release**, attach the `.apk` file, publish the release, and paste the release asset link here.
